# ERP Patrimonio Maven Quickstart

Minimal Maven Java project for ERP Patrimonio.

## Build

```sh
mvn clean package
```

## Run

```sh
java -cp target/erp-patrimonio-1.0.0-SNAPSHOT.jar com.erp.patrimonio.App
```

## Test

```sh
mvn test
```

# ERP Patrimônio

Sistema ERP desenvolvido em Java para gerenciamento patrimonial.

## Tecnologias

- Java 21
- Maven
- Git
- PostgreSQL (futuro)

## Objetivo

Desenvolver um ERP completo seguindo boas práticas de arquitetura, código limpo e versionamento.
